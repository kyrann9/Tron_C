# Tron_C
Compilation :
Afin de compiler le projet, il est nécessaire d'utiliser la commande make dans le dossier contenant le Makefile du projet.

Lancement :
Le projet est lancé en exécutant "./exec" qui est créé par le Makefile
Il sera alors demandé à l'utilisateur de choisir l'interface graphique voulue, SDL, NCurses, ou les deux.
L'utilisateur devra aussi de choisir si il joue seul contre un bot, ou à deux joueur
